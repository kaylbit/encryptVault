🔐 Encrypt and Decrypt Tool (Base64)

	This is a simple Python program that allows you to encrypt and decrypt messages using Base64 encoding. It also supports saving encrypted outputs for later use and checking/decrypting saved data.
	
📌 Features

	•✅ Encrypt text into Base64
	•✅ Decrypt Base64 strings
	•✅ Save encrypted results into memory
	•✅ View saved encrypted data
	•✅ Decrypt from saved list
	•✅ Error handling for invalid inputs

📂 Example Run

	WELCOME TO ENCRYPT AND DECRYPT!
	--------------------
	1. Encrypt.
	2. Decrypt.
	3. Check encrypted saves.
	4. Exit

	Choose an action [1, 2, 3, 4]: 1
	input word to encrypt: hello
	Input has been encrypted to 'aGVsbG8='.
	Add to save?[y/n]: y
	Addded to save.

🛠️ Requirements

	Python 3.x
	No external libraries are required (uses built-in base64).
